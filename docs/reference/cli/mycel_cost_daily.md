## mycel cost daily

Show daily cost totals

### Synopsis

Show daily cost totals for the last N days.

Examples:
  mycel cost daily              # Last 30 days (default)
  mycel cost daily --days 7     # Last 7 days
  mycel cost daily --json

```
mycel cost daily [flags]
```

### Options

```
      --days int   Number of days to show (default 30)
  -h, --help       help for daily
```
