## mycel cost agent

Show per-agent cost breakdown

### Synopsis

Show cost breakdown by agent. If a name is given, shows detail for that agent.

Examples:
  mycel cost agent                    # All agents
  mycel cost agent swift-falcon       # Specific agent

```
mycel cost agent [name] [flags]
```
