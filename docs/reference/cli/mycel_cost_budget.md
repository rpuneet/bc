## mycel cost budget

Manage cost budgets

### Synopsis

Commands for managing cost budgets and limits.

Examples:
  mycel cost budget show
  mycel cost budget set 100.00
  mycel cost budget set 50.00 --agent engineer-01
  mycel cost budget set 500.00 --period monthly --alert-at 0.9
