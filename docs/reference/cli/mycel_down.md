## mycel down

Stop mycel services

### Synopsis

Stop the mycel daemon and database Docker containers for this workspace.

Examples:
  mycel down
  mycel down --workspace /path/to/workspace

```
mycel down [flags]
```

### Options

```
  -h, --help               help for down
      --workspace string   Workspace directory (defaults to current workspace)
```
