## mycel app

Manage app (gateway plugin) integrations

### Synopsis

Manage app plugins — the integrations that bridge mycel to external
platforms (Slack, GitHub, webhooks, ...).

Examples:
  mycel app scaffold linear      # Generate a new app plugin skeleton
