## mycel channel react

React to a channel message

### Synopsis

Add an emoji reaction to a message in a channel.

The message-index is shown in 'mycel channel history' output.
Use common emoji like 👍, 👎, ❤️, 🎉, 👀, 🚀 or any emoji.

Examples:
  mycel channel react engineering 5 👍
  mycel channel react general 0 🎉

```
mycel channel react <channel> <message-index> <emoji> [flags]
```
