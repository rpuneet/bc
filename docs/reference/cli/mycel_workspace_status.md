## mycel workspace status

Show workspace status and agent health

### Synopsis

Show a health overview of the workspace: running agents, idle agents,
config validity, and uptime.

Examples:
  mycel workspace status         # Status overview
  mycel workspace status --json  # JSON output

```
mycel workspace status [flags]
```
